# 🖥️ Web OS / Sanal Masaüstü

Tarayıcı üzerinde çalışan, sürüklenip kapatılabilen pencere sistemine ve çeşitli mini uygulamalara sahip eğlenceli bir Web İşletim Sistemi projesi! 🚀

---

## 🚀 Özellikler

- 🖥️ **Masaüstü & Görev Çubuğu:** Başlat menüsü, saat ve ikonlar.
- 🪟 **Sürüklenebilir Pencereler:** Pencereleri açma, kapama, küçültme ve ekranda taşıma.
- 📂 **Dahili Mini Uygulamalar:**
  * 📝 **Not Defteri (Notepad):** Hızlı not alma uygulaması.
  * 🧮 **Hesap Makinesi:** Çalışır durumda mini hesap makinesi.
  * 🎨 **Çizim Panosu (Paint):** Basit tuval üzerinde çizim yapma.
  * 🕹️ **Mini Oyun / Ses Tahtası:** Eğlenceli vakit geçirmek için küçük araçlar.
- 🔊 **Ses Efektleri:** Tıklama, pencere açma ve hata sesleri.

## 🛠️ Kullanılan Teknolojiler

- **HTML5** - Masaüstü ve pencere yapıları
- **CSS3** - Masaüstü teması, pencere stilleri ve z-index katman yönetimi
- **JavaScript (ES6+)** - Drag & drop (sürükle-bırak) mantığı, pencere yönetimi ve Web Audio API
